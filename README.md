# 📋 哲恒 排班登记 - 使用说明

这是一个自用的 **PWA 网页应用**，参照《哲恒排班登记模版（日期列）.xlsx》设计，
在安卓手机上像原生 App 一样使用。数据全部保存在手机浏览器本地，无需联网。

---

## 一、与 Excel 模板的对应关系

| Excel 模板 | 本应用 |
|-----------|--------|
| 底部 12 个月工作表 | 顶部月份导航（‹ › 切换 1~12 月） |
| 日期 + 星期列 | 月历视图，自动生成星期 |
| 每天固定 3 行（场次 1/2/3） | 每天最多 3 场，空场次点「＋」添加 |
| 门店下拉（4 家店） | 门店下拉选择，可「✏️ 自定义」 |
| 时间段下拉（8 个常用段） | 时间段下拉选择，可「✏️ 自定义」 |
| 年份单元格（黄色） | ⚙️ 设置 → 年份 |
| 右侧「XX月统计」面板 | 「本月统计」卡片，自动计算 |
| 复用到其他歌手 | ⚙️ 设置 → 歌手名称 |

## 二、功能清单

- ✅ 12 个月循环查看，每天最多 3 场（场次 1/2/3）
- ✅ **当天 3 场横排大卡，已录 / 空闲一目了然，点卡即编辑或添加**
- ✅ 每场登记：门店 + 时间段 + 备注
- ✅ 门店 / 时间段下拉选择，列表没有的可直接自定义输入
- ✅ **门店筛选：点选某家门店，查看该店当月全部排班日期，月历圆点同步联动**
- ✅ **本月统计：大数字 + 环形图 + 各门店进度条，场次分布直观可视**
- ✅ 一键导出本月排班为 CSV（Excel 可直接打开）
- ✅ 到点提醒（🔔 开关，按时间段开始时间提醒）
- ✅ **多设备同步（可选）：手机 + 电脑数据自动互通**
- ✅ 添加到手机桌面，离线也能打开
- ✅ **已内置《哲恒排班登记模版（日期列）.xlsx》中 8 月已有排班 52 场，打开即用**

## 五、电脑上看效果

1. 打开浏览器访问：http://localhost:8080
2. 默认打开**今天所在的月份**，点日期 → 点空场次「＋」→ 选门店、时间段 → 保存

## 六、安卓手机上使用（局域网）

1. **手机和电脑连同一个 WiFi**。
2. 手机浏览器（推荐 Chrome / Edge / 华为浏览器）打开：

   ```
   http://192.168.1.59:8080
   ```

3. **添加到主屏幕**：浏览器菜单 →「添加到主屏幕 / 安装应用」→ 桌面出现「排班登记」图标，之后像普通 App 一样点开即用。
4. 添加成功后会自动缓存到手机本地，**离线也能打开和查看**。

## 七、开始登记

1. 月历上点选日期（或点「今」回到今天）。
2. 当日排班列表显示场次 1/2/3，空场次是虚线框，点击添加。
3. 选择场次、门店、时间段（列表里没有的 → 点「✏️ 自定义」输入新值）。
4. 保存后该日期下方出现小圆点，统计面板自动更新。
5. 点已登记的场次卡片可编辑或删除。

## 八、提醒功能

1. 点右上角小铃铛 🔔 开启（首次需允许浏览器通知）。
2. 每场时间段的**开始时间**到点时，手机会弹通知（如 23:30-00:10 → 23:30 提醒）。
3. 为保证提醒有效，浏览器请保持后台运行。

## 九、导出到 Excel

- 「本月统计」卡片右上角有「导出 CSV」按钮。
- 点击后下载一个 CSV 文件，用 Excel / WPS 打开即可查看和打印，格式与模板一致（日期、星期、场次、门店、时间段、备注）。

## 十、多设备同步（手机 ↔ 电脑数据互通）🔄

> 默认数据只保存在当前设备。开启同步后，**手机上登记的排班，电脑打开自动就有**，反之亦然。
> 数据存放在**你自己 GitHub 账号的私有 Gist** 里，只有你能看到。

**开启步骤（每台设备做一次）：**

1. 电脑浏览器打开（需登录 GitHub）：
   ```
   https://github.com/settings/tokens/new?scopes=gist&description=排班数据同步
   ```
   直接点页面底部的绿色 **Generate token** 按钮 → 复制生成的一串字符（`ghp_` 开头）。

2. 打开排班应用 → ⚙️ 设置 → 找到「**多设备同步**」→ 粘贴 Token → 点「**绑定**」。

3. 第一台设备绑定后，云端自动创建备份；**第二台设备重复上面两步**，会自动拉取云端数据合并进来。

**工作方式：**

- 排班有改动后约 3 秒自动推送到云端；打开应用 / 切回前台 / 每 5 分钟也会自动拉取。
- 断网时改动先存本机，联网后自动补同步。
- 两台设备同时改同一场排班 → **保留较新的一次修改**；在一台设备上删除的记录，另一台也会同步删除。
- 顶部状态栏实时显示：`🔄 已同步` / `⏳ 待同步` / `⚠️ 同步失败`。

**不想同步了？** 设置里点「解绑」即可，数据仍然完整保留在本机。

> ⚠️ Token 相当于你 GitHub 的一把钥匙（只有 Gist 读写权限），只粘贴在这个应用里，不要发给任何人。

## 十一、设置（⚙️）

- **歌手名称**：改成你的名字，标题和导出文件名都会跟着变。
- **年份**：默认 2026，改年份后月历日期自动重排（支持闰年 2 月 29 日）。
- **门店列表 / 时间段列表**：可增删下拉选项；也可以直接在登记时用「✏️ 自定义」临时输入。

## 十二、数据安全

- 所有排班数据保存在设备浏览器本地（localStorage），不上传任何服务器。
- 开启「多设备同步」后，数据会额外加密存储在**你自己账号的私有 Gist**（仅 gist 权限 Token 可访问），不会公开。
- 未开启同步时：换手机 / 清浏览器数据会丢失，建议每月用「导出 CSV」备份一次。
- GitHub Pages 只是**托管应用代码**，你的排班数据始终只在你自己的设备（和私有 Gist）里。

## 十三、常见问题

**Q：为什么每天只能登记 3 场？**  
A：与 Excel 模板一致（每天固定 3 行）。超过 3 场模板建议记在备注里，本应用会提示。

**Q：换歌手 / 换门店怎么改？**  
A：⚙️ 设置里改歌手名称；门店和时间段可增删，登记时也可随时自定义。

**Q：提醒不弹怎么办？**  
A：检查：① 铃铛开关已开启；② 浏览器通知权限已允许；③ 浏览器没被系统杀掉后台。

**Q：怎么导出数据？**  
A：「本月统计」卡片 →「导出 CSV」，Excel/WPS 直接打开。

**Q：手机上同步失败（⚠️ 同步失败）怎么办？**  
A：手机网络访问 GitHub 有时需要代理。稍等会自动重试；如果长时间不行，可在有代理的环境下打开一次让数据追平。数据始终有本地副本，同步失败**不会丢数据**。

**Q：两台设备都改了同一场排班，以哪台为准？**  
A：以**修改时间较新**的那次为准（精确到毫秒）。建议避免同时在两台设备上编辑同一天的排班。

**Q：想换一个 GitHub 账号同步？**  
A：设置里先「解绑」，再用新账号的 Token 绑定即可。
